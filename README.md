# WeiDoctor v1.0 beta

WeiDoctor is a Slay the Spire 2 beta mod prototype that adds a Doctor character, operator deployment slots, dispatch center progression, bond-layer relics, and three-copy promotion mechanics.

This repository currently contains design data, assets, and C# implementation scaffolding. It is not yet a fully compiled playable mod until the Slay the Spire 2 beta modding API / loader bindings are connected.
